537+  6D91
538+  6D91              ; IN: HL=source in host RAM, BC=payload byte count (1..#2FFE).

540+  6D91              ;      and disabled DMA. Carry set on timeout.

542+  6D91              ; Protocol:
543+  6D91              ;   host OUT GSCOM,CMD_LOAD_X86 -> CBIT=1
