PROJECT 124 — ИСПРАВЛЕНИЕ BASIC BOOTLOADER

Найден дефект строки 20 в BASIC-загрузчике.

Было в исходной версии:
  RANDOMIZE USR 15619: REM: LOAD "proj124" CODE 24576

После REM остаток строки не исполнялся как BASIC-команды. Кроме того,
слова LOAD/CODE в старой версии были записаны обычными ASCII-символами,
а не токенами Sinclair BASIC. Строка 21 при этом безусловно печатала
LOADED, поэтому этот маркер не доказывал, что машинный код был загружен.

Исправлено в zx_main/boot_loader.asm:
  RANDOMIZE USR 15619: LOAD "proj124" CODE 24576

LOAD записан токеном #EF, CODE — токеном #AF. Число 24576 имеет
правильный пятибайтовый числовой маркер Sinclair BASIC (#0E, low/high).
В основном исходнике файл создаётся командой:
  SAVETRD "disk_A.trd", "proj124.C", 24576, ProgramEnd - 24576
Имя LOAD "proj124" соответствует имени TR-DOS файла proj124.C.

Ожидаемая последовательность отладки:
  P124 START
  LOADED
  байт #02 (строка 30)
  байт #AA (первая инструкция Init_Z80_System по адресу #6009)

Если после исправления появляется LOADED, но нет #AA, следующий этап
диагностики — проверить содержимое proj124.C на диске и фактические
первые 16 байт файла. Саму сборку/запуск в эмуляторе в этой среде
не выполнял; выдавать это за проверенный запуск нельзя.
