  2++ 02C2              ; PROJECT 124 — 8086 physical memory backend for NeoGS GS105a
  3++ 02C2              ;
  4++ 02C2              ; x86 physical $00000-$FFFFF maps to NeoGS RAM pages 4..67
  5++ 02C2              ; (NeoGS physical base $010000, page size $4000 / 16 KiB).
  6++ 02C2              ; Window C000-FFFF is switched through MPAGEX. This keeps firmware in
  7++ 02C2              ; window 0 / page 0 and the current DMA frame in window 1 / page 3.
