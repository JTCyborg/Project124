# Отложенные испытания NeoGS / IPC / DMA

Статус: **отложено**. Эти проверки не входят в текущий этап реализации x86-эмулятора; вернуться к ним после стабилизации базового CPU.

## Список задач

- [ ] **Тайм-аут DMA при прерывании передачи посередине.** Проверить, как хост и NeoGS обнаруживают незавершённую передачу, закрывают DMA, сбрасывают CBIT/DBIT и возвращаются в согласованное состояние.
- [ ] **Тайм-аут DBIT, если принимающий процессор не читает переданный байт.** Проверить ограниченное ожидание, реакцию передающей стороны и отсутствие зависания IPC.
- [ ] **Возврат к штатной GS105a ROM через `#F4`.** Проверить переход из пользовательской прошивки к штатной ROM, восстановление отображения ROM и доступность штатного загрузчика.
- [ ] **Повторная загрузка пользовательской прошивки после возврата к штатной ROM.** Выполнить полный цикл: пользовательская прошивка → `#F4` → штатная ROM → повторная загрузка bootstrap и пользовательской прошивки → подтверждение готовности.
- [ ] **Длительная работа и большие передачи.** Провести нагрузочные испытания DMA/IPC на больших блоках и многократных циклах; фиксировать ошибки, зависания и целостность данных.
- [ ] **Восстановление после аварийного сброса одного из процессоров.** Проверить сценарии независимого сброса Z80 NeoGS и Z80 хоста, очистку зависших флагов/состояний и безопасную повторную синхронизацию.

## Критерий закрытия

Для каждой проверки сохранить лог, указать сценарий отказа, ожидаемое и фактическое поведение, а также подтверждение восстановления без полной перезагрузки системы (если это технически возможно).

## Контекст

Базовый успешный прогон зафиксирован в журнале проекта: пять тестов интерпретатора прошли через DMA; основной тест завершился со статусом `0000` и AX=`BBAB`. Успешный штатный запуск сам по себе не проверяет перечисленные аварийные сценарии.
